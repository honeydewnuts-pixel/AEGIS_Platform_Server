# ARRS Research Governance Specification

## Preregistration
Before outcome inspection: candidate definition, features, splits, costs, metrics, acceptance criteria.  
Post-hoc changes → new candidate version.

## Data separation
Chronological development / validation / holdout.  
Feature causality: completed bars only.  
Exposed holdouts must be labelled; not claimed as independent confirmation.  
Pattern-discovery final 20% is **EXPOSED**.

## Multiple testing
Prior study: 2640 evaluations.  
ARRS stage 1: record search-space size and selection path.  
Stage 2+: FDR or family-wise controls where dependence structure allows; always prefer independent confirmation over p-value theatre.

## Cost-aware evaluation layers
1. Association (forward returns)  
2. Path (MFE/MAE) with MFE−MAE vs cost  
3. Executable cash only after trade-management prereg  
Class A Bid/Ask vs Class B OHLC never pooled as executable proof.

## Cross-instrument claims
Require leave-one-out or holdout instruments frozen before transfer claims.  
Shared pattern names ≠ transfer proof.

## Qualification
Multi-metric: expectancy after costs, uncertainty, drawdown, support, stability, operational feasibility.  
No single hit-rate gate.
